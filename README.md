## 個人回答

### 問題一 為什麼以 3 人計費?
測試一整理完的桌遊串列是 ['amy', 'ben', 'amy', 'cora']，雖然看起來有 4 筆，但 'amy' 其實重複出現了兩次。依照作業規則，同一個人在同一場活動重複報名只算 1 位、也只收 1 次錢，去重之後實際參加的人只有 {'amy', 'ben', 'cora'} 這 3 位，所以桌遊費用是用 3 人來算（3X120 = 360元）。至於直接用 split(",") 拆成 list，跟再轉成 set，兩者差別在於：拆成 list：保留了原本報名的先後順序，也保留了重複出現的次數（看得出來誰填了兩次、順序是怎樣）；但失去了「不重複」的特性，也不能直接做交集、聯集或差集，用 len() 算出來的是資料筆數而不是實際人數。轉成 set：保留了去重後的參加者名單，而且可以直接用集合運算比對兩場誰有來、誰沒來；但失去了原本的排列順序，也失去了重複幾次的資訊（重複報名會被合併成同一個元素）。
### 問題二 測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
測試三裡，桌遊去重後是 {'amy', 'ben', 'cora'}（3 人），電影去重後也是 {'amy', 'ben', 'cora'}（3 人）。因為兩場名單完全一樣，所以交集跟聯集都是這 3 個人（共同人數 3 人、總不重複人數 3 人），兩個方向的差集就都是空的（set()，印出來是 []）。雖然總共只有 3 位不同的人，但這 3 個人兩場都參加了，「報名人次」是把兩場去重後的人數加起來（同一人跨場算兩次），費用也是兩場分開算，所以：報名人次：3 + 3 = 6（人次）桌遊應收：3X120 = 360（元）電影應收：3X80 = 240（元）總應收：360 + 240 = 600（元）
